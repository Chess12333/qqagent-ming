# 更好的主动聊天插件 1.0

在**不改核心**的前提下，把主动聊天收得更像人：

- 晚上 **23:00–次日 07:00 不主动找人**；早上恢复。
- 保留白天原有概率，但加**最小间隔 / 每天上限 / 单轮上限**。
- 可选允许分享 **B站视频 / 歌 / 网页链接**，默认全关。
- **B站视频改成“封面图 + 标题链接”**，不再发 QQ 卡片（卡片在 QQ 里根本点不开）。
- 筛选全靠主模型自己判断，**不额外调用小模型**。

## 安装

1. 打开控制台 →「工具与扩展」→「导入 ZIP」。
2. 选择 `更好的主动聊天插件-1.0.0-插件包.zip`。
3. 打开「设置 → 更好的主动聊天插件」，按需配置 → 点「启用」→「保存设置」。

宿主的 ZIP 导入不会覆盖同名目录；以后升级用覆盖包，或先删 `plugins/proactive-plus/` 再导入。

## 夜间静音怎么做

- 到点后，插件会临时把核心的
  `proactive.enabled`、`proactive.privateIdleEnabled`、`proactive.privateScheduleEnabled`
  写成 `false`，这样**连主动唤醒一起停**，不是只拦发送。
- 早上恢复时，只恢复“当前值仍是我们写进去的 false”的键。
  **你夜里手动改过的键不会被覆盖。**
- 备份写在插件自己的配置 `skills.proactive-plus.quietSession`，状态盘在
  `<dataDir>/proactive-plus-state.json`。进程在夜里被关掉、第二天启动时会自动对账。
- 禁用插件或卸载时会把仍归它控制的键恢复。
- 另外还有一条硬拦：静音时段里即使核心仍唤醒了主动轮，插件的 `before-tool`
  会把所有对外发送（文字/图/表情/歌/B站/拍一拍）直接拦下。

## 主动额度

当前版本不再向模型追加“更好的主动聊天插件 · 本轮”动态提示。静音、最小间隔、每天/单轮上限仍在实际发送前执行；固定分享规则继续保留。模型可能先尝试发送，再收到额度拦截结果。

- 同一轮最多 `maxPerRound` 条（默认 2）。
- 两次主动至少隔 `minIntervalMin` 分钟（默认 120）。
- 每天最多 `maxPerDay` 次（默认 3）。
- `0` = 不限（单轮上限除外）。
- 只作用于**主动轮**；日常回复不占主动额度。

## 分享内容

默认全关。按需打开：

| 类型 | 模型会用的工具 | 关掉时 |
|---|---|---|
| B站视频 | `send_bilibili` | 只拦主动分享；你点名要时仍允许（仍改标题+链接） |
| 歌 | `search_music` → `send_music` | 只拦主动分享；你点名要时仍允许 |
| 网页链接 | `web_search` / `fetch_web` → `send_message` | 只拦主动轮；日常明确要链接仍允许 |

- 主动分享还受 `shareMinIntervalMin`（默认 240 分钟）和 `shareMaxPerDay`（默认 1 次）限制。
- “值得占用一次注意力”的筛选是**提示词规则 + 主模型自己判断**：
  有信息量、有趣、和对方/话题有关、能自然接话；不发广告/带货/标题党/低质搬运/争议/隐私；同一内容或作者不短期重复。
- 设置页可以追加自己的筛选口径，会接在内置规则后面。

## B站视频为什么改了

核心里 `send_bilibili` 的说明写的是“封面图 + 标题链接”，但实现只发一张
`bilibili_card`（JSON 卡片），QQ 里经常点不开。本插件在 `before-tool` 里：

1. 用 B站公开接口查标题和封面（有配置 `webSearch.bilibiliCookie` 就带上）；
2. 把这次调用改成核内 `send_message`，先发 **标题 + 链接**（走正常回执链，保证可见）；
3. 再尽力把**封面图**单独发一次；封面失败不影响标题+链接。

所以模型仍然正常调 `send_bilibili`，只是实际发出去的是“标题链接 + 封面图”。
`send_message` 里手拼 `bilibili_card` 的野路子不在覆盖范围；请让模型用 `send_bilibili`。

## 数据与隐私

- 只写 `data/config.json` 的 `skills.proactive-plus`，以及
  `<dataDir>/proactive-plus-state.json`（只有额度计数与静音备份，不含聊天正文）。
- 不写插件目录；不联网抓聊天内容；B站接口只查视频公开元信息与封面。
- 不含任何真实 QQ 号、群号、聊天记录或密钥。

## 常见问题

- **晚上还是会跑模型？** 看设置页顶部是否显示“当前处于静音时段”。如果核心 proactive
  的键在夜里被手动打开过，插件不会覆盖你的改动；硬拦发送仍然生效。
- **早上没恢复？** 关闭再启用插件，或看 `quietSession` 是否还在；插件在启动/下个 tick 会对账。
- **B站只发了文字没有封面？** 封面接口失败或超过大小限制时会只发标题+链接；这是有意的降级。
- **分享了但很频繁？** 检查 `shareMinIntervalMin` / `shareMaxPerDay`；日常聊天里
  对方点名要的不拦，但会记一次“最近分享”。
- **插件默认关闭**：导入后需要到设置页点“启用”。

## 兼容

- 新树插件 API v1；老树未验证。
- 需要核心的 `send_message`、`send_bilibili`、`send_music` 工具按正常权限开着；
  插件只改这些工具的执行前行为，不替代它们。
